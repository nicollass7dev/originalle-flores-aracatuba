# Floricultura Originalle

Site institucional e catálogo da Floricultura Originalle, em Araçatuba/SP.

## Estrutura

- `dist/index.html`: página principal
- `dist/styles.css`: identidade visual e responsividade
- `dist/script.js`: navegação, animações e formulário para WhatsApp
- `dist/assets/`: logotipo e fotografias da floricultura

## Executar localmente

Sirva a pasta `dist` com qualquer servidor HTTP estático.

## Publicação

O projeto está configurado para publicação estática na Vercel por meio do arquivo `vercel.json`.
